# 🛠️ Stack-Tools

> **Tu navaja suiza digital para organizar el ecosistema de desarrollo.**

[![Estado](https://img.shields.io/badge/Estado-Beta_Pública-blueviolet)](https://github.com/carlitic/stack-tools)
[![Tecnología](https://img.shields.io/badge/Stack-Vanilla_JS-yellow)](https://developer.mozilla.org/es/docs/Web/JavaScript)
[![Backend](https://img.shields.io/badge/Backend-Supabase-green)](https://supabase.com)

**Stack-Tools** es una Single Page Application (SPA) diseñada para ayudar a desarrolladores a centralizar, categorizar y acceder rápidamente a su documentación, librerías y utilidades favoritas. Olvida el caos de los marcadores del navegador.

## ✨ Características

-   **⚡ Arquitectura SPA**: Navegación fluida sin recargas, construida con Vanilla JavaScript.
-   **🎨 Diseño Premium**: Interfaz minimalista con **Glassmorphism**, modo oscuro/claro y animaciones fluidas.
-   **📱 100% Responsive**: Adaptada perfectamente a móviles, tablets y escritorio.
-   **🔐 Autenticación Segura**: Sistema de Login/Registro integrado con **Supabase Auth**.
-   **📂 Gestión de Herramientas**: CRUD completo (Crear, Leer, Editar, Eliminar) tus herramientas con detección automática de Favicons.
-   **🏷️ Categorías Personalizadas**: Crea y organiza tus propias categorías para ordenar tu stack.
-   **🔍 Buscador Inteligente**: Filtra tus herramientas instantáneamente por nombre, URL o categoría.
-   **📤 Exportación PDF**: Genera un reporte de tu stack en formato PDF con un solo clic.
-   **⚠️ Modo Demo**: Prueba la interfaz sin necesidad de configurar una base de datos.

## 🚀 Tecnologías

Este proyecto ha sido desarrollado como parte de la profundización en **Desarrollo de Aplicaciones Web (DAW)**, priorizando el uso de estándares web modernos sin depender de frameworks pesados:

*   **HTML5 & CSS3**: Variables CSS, Flexbox, Grid y Animaciones. Estructura semántica.
*   **JavaScript (ES6+)**: Lógica de cliente, Router SPA personalizado, Gestión de estado.
*   **Supabase Client**: Integración directa con base de datos PostgreSQL y políticas RLS (Row Level Security).
*   **Librerías Auxiliares**: `html2pdf.js` (Exportación), `Boxicons` (Iconografía), `Toastify` (Notificaciones).

## 🛠️ Instalación y Uso

### 1. Clonar el repositorio

```bash
git clone https://github.com/carlitic/stack-tools.git
cd stack-tools
```

### 2. Ejecutar localmente

Al ser una aplicación estática, puedes abrir directamente el archivo `index.html` en tu navegador, o usar un servidor local para una mejor experiencia:

```bash
# Si tienes Python instalado
python3 -m http.server

# O con la extensión "Live Server" de VS Code
```

### 3. Configuración del Backend (Opcional)

Para persistir tus datos, necesitas crear un proyecto gratuito en [Supabase](https://supabase.com):

1.  Crea un nuevo proyecto.
2.  Ejecuta este SQL en tu editor de Supabase para crear la tabla de herramientas y categorías:
    ```sql
    -- Tabla de Categorías (Opcional, si quieres personalizarlas)
    create table categories (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      name text not null,
      user_id uuid references auth.users not null
    );

    -- Tabla de Herramientas
    create table tools (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      name text not null,
      url text not null,
      category text not null,
      user_id uuid references auth.users not null
    );
    ```

3.  Copia tu `URL` y `ANON KEY` del proyecto.
4.  Pégalos en el archivo `app.js`:
    ```javascript
    const SUPABASE_URL = 'tu-url-aqui';
    const SUPABASE_KEY = 'tu-key-aqui';
    ```

> Si no configuras Supabase, la aplicación funcionará en **Modo Demo** (los datos no se guardarán al recargar).
